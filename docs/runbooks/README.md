# Runbooks

This directory is the home for operational runbooks required before production.

Phase 1 creates the documentation home only. Later phases will add runbooks for Railway setup, staging deployment, production deployment, rollback, key creation/revocation, provider key rotation, budget changes, spend alerts, provider outage handling, backups, restore, and prompt/log leakage investigation.

Do not store secrets, generated virtual keys, database URLs, backup credentials, private hostnames, or raw incident payloads in runbooks.
